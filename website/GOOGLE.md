# Make Spindle show up on Google

Public URL: **https://maxmccutcheon59.github.io/spindle/**

## 1. Turn on GitHub Pages (one-time)

1. Open https://github.com/maxmccutcheon59/spindle/settings/pages  
2. **Source:** GitHub Actions  
3. Save

## 2. Deploy

- Push to `main` (website files), or  
- Actions → **Deploy website** → Run workflow  

When green, open https://maxmccutcheon59.github.io/spindle/

## 3. Ask Google to index it

1. https://search.google.com/search-console  
2. Add property: `https://maxmccutcheon59.github.io/spindle/`  
3. Sitemaps → submit `sitemap.xml`  
4. URL Inspection → **Request indexing** for the homepage  

## 4. What to Google

- `Max McCutcheon Spindle`  
- `Spindle Cloud Max McCutcheon`  
- `maxmccutcheon59 spindle`  
- `site:maxmccutcheon59.github.io spindle`  

Indexing is not instant — usually hours to a few days after the site is public and submitted.
